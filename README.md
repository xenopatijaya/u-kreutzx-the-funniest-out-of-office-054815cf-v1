An entry for make.fun's "The Funniest Out-of-Office" bounty: https://make.fun/c/u-kreutzx-the-funniest-out-of-office-054815cf

The program writes a one-line out-of-office reply to `/output/entry.txt`: the sender is away reenacting their inbox in interpretive dance, and urgent matters can only reach them if you applaud louder.

## Run it

```sh
python3 main.py
```

This writes the reply to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
